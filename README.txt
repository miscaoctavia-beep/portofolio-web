LANDING PAGE PRIBADI — TUGAS RUTIN 1

File:
- index.html
- style.css
- profile.svg

Semua poin pada instruksi tugas sudah dicakup:
1. DOCTYPE dan lang="id"
2. charset UTF-8 dan viewport
3. title dan meta description
4. header, nav, main, article, section, aside, footer
5. form dengan label, input, textarea, button dan validasi HTML5
6. gambar lokal dengan alt + figure + figcaption
7. heading h1 -> h2 -> h3
8. navigasi anchor dengan #id
9. footer dengan copyright
10. Open Graph meta tags (bonus)
11. time untuk tanggal (bonus)
12. input date, color, range (bonus)
13. CSS responsive untuk HP dan laptop

Sebelum dikumpulkan:
- Ganti teks "Portofolio Saya" dan isi profil/proyek sesuai data kamu.
- Buka index.html di browser dan cek semua menu.
- Tes form: klik Kirim Pesan saat ada kolom kosong untuk melihat validasi.
- Cek HTML di W3C Validator: https://validator.w3.org/
- Upload index.html, style.css, dan profile.svg ke repository GitHub pribadi.
